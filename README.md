# WeatherSphere ☀️

A beautiful, responsive weather application that provides current weather conditions and forecasts using the Open-Meteo API.

# Features

- Real-time weather data for any location
- 5-day weather forecast
- Current weather details (temperature, humidity, wind speed, etc.)
- Automatic location detection
- City search functionality
- Dynamic background based on time of day
- Responsive design for all devices
- Sleek UI with weather animations

# Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Open-Meteo API (free weather API)
- Font Awesome icons
- Google Fonts
